# Multi Well Viewer

This repository is intended to serve as the foundation for a multi well viewer application.

## Project Overview

The Multi Well Viewer will provide functionality to visualize and analyze data from multiple wells.

## Getting Started

1. **Clone the repository**:
   ```
   git clone https://github.com/AnshulChoudhary-iitism/multi-well-viewer.git
   ```
2. **Install dependencies**:
   ```
   npm install
   ```
3. **Run the application**:
   ```
   npm start
   ```
